# Repository for the analysis of pathogen associated genes in a set of Pseudomonas spp. 

The data for this analysis was obtained in a cohort of non-cystic fibrosis bronchiectasis patients. Total number of samples are 190 isolates from *Pseudomonas aeruginosa*, some patients with repeated isolates. 

The manuscript can be found at https://erj.ersjournals.com/content/49/4/1602108.abstract

Briefly, we will
1. verify the quality of raw (trimmed) reads
2. assemble the genomes
3. BLAST the interesting sequences in the resulting genomes
